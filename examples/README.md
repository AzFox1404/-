# Local examples

Клиентские документы не входят в репозиторий. Для интеграционных проверок укажите каталог своей копии комплекта через `BUREAU_ID_EXAMPLES_DIR` или `.project-local.json` (оба варианта локальные). Проверки `verify_*` с Word/Excel работают на временных копиях; перед их запуском читайте описание в `docs/DEVELOPMENT.md`.
