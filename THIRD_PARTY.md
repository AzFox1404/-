# Сторонние компоненты

Исходная лицензия проекта пока не выбрана. Репозиторий частный; публикация кода здесь не назначает ему автоматически лицензию MIT.

- `vendor/tkdnd-win-x64/` — существующий комплект TkDND 2.10.3 Windows x64 для drag-and-drop. Исходный `LICENSE` и copyright-заголовки Tcl сохранены. DLL — единственный бинарный runtime-ресурс в исходниках.
- Python-зависимости устанавливаются отдельно: Pillow, openpyxl, python-docx/lxml, pypdf, pypdfium2/PDFium, PyMuPDF. Их собственные лицензии сохраняют силу.
- ReportLab используется только частью проверок.
- Word/Excel и Windows OCR используются через установленные на ПК компоненты и не включены в репозиторий.

До распространения EXE отдельно проверить условия всех включаемых компонентов, в частности PyMuPDF (варианты AGPL/коммерческой лицензии). Этот файл — учёт зависимостей, а не юридическое заключение.
