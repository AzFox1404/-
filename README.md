# Бюро ИД

Проект по заполнению исполнительных документов для строительных компаний инженерами.
Windows-приложение для инженеров ПТО: заполнение Word/Excel по исходным формам, каталог паспортов и сертификатов, реестры и сборка PDF.

## Запуск

Нужны **Windows x64, Python 3.11+ с Tkinter и установленный Microsoft Office (Word и Excel)**.

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.\"Бюро ИД.cmd"
```

На рабочем компьютере запуск также поддерживает уже имеющуюся среду Codex. EXE ещё не собран; перенос исходников не заменяет установку Office и зависимостей.

## Что умеет приложение

- Импорт отдельного документа, папки или ZIP; Word DOC/DOCX и Excel XLS/XLSX.
- Дерево документов и библиотека; выбор вариантов и ручной ввод; сохранение черновиков.
- Анализ известных форм АОСР/АООК, приложений, титулов и реестров; ручные привязки для неизвестных форм.
- PDF-предпросмотр в отдельном процессе, масштаб, поворот, выделение и копирование текста.
- Разбор PDF/JPEG документов качества: проверка границ, разделение, реквизиты и каталог. OCR использует Windows.
- Очередь вставки/удаления строк реестра; нумерация и страницы по количеству листов.
- Сборка общего комплекта, отдельных PDF или разделов; связи документов и выбор дубликатов.
- Отделяемые/сворачиваемые панели, светлая и тёмная темы, восстановление незавершённой работы.

## Работа

Выберите источник на главной, дождитесь анализа и проверьте назначенные поля. Слева документы и библиотека, в центре ввод, справа печатный вид PDF. Постоянные подписи, пояснения и исходная структура формы сохраняются.

В реестрах вводится количество листов; страницы рассчитываются автоматически. Вставка на первой позиции создаёт строку перед ней, остальные вставки — после выбранной. После удаления нижние записи сдвигаются вверх.

Ввод и предпросмотр работают с отдельной рабочей копией. Переименование не сохраняет введённый текст. «Сохранить» подтверждает запись документа; «Не сохранять проект» при закрытии возвращает весь проект к состоянию на момент открытия, включая имена файлов.

Красный текст и жёлтая строка — временные отметки предпросмотра. После структурных операций отмечаются только итоговые суммы. Рабочие файлы, экспорт и печатный комплект сохраняются без этих цветов.

Ctrl+C/V/X, Ctrl+Z/Y работают в полях. Ctrl+колёсико меняет масштаб PDF; обычное колесо прокручивает. Нажатие колёсика включает ускоряемую прокрутку, повторное нажатие или Esc выключает её.

Кнопка «—» скрывает только панель; «Вернуть» восстанавливает её ввод и просмотр. Окна паспортов и сборки сворачиваются в панель задач Windows; их кнопки отделения убраны. В полноэкранном режиме нижние 24px окна раскрывают системную панель задач при наведении.

## Где данные

По умолчанию пользовательские проекты, библиотека, настройки и восстановление лежат в `Рабочая папка ИД/` рядом с программой. Эта папка **не публикуется в Git**. Для другого расположения задайте `BUREAU_ID_DATA_DIR`.

Ссылки на локальные проверочные примеры можно задать в `BUREAU_ID_EXAMPLES_DIR` или `.project-local.json`. Исходные документы компаний и паспорта в репозиторий не включены. В `data/act_anchors.json` хранятся только обезличенные постоянные подписи известных Excel-форм.
