# Подтверждённые требования

## Формы и ввод

Windows-приложение для ПТО; Office установлен. Поддерживаются Word DOC/DOCX, Excel XLS/XLSX, проектные PDF, паспорта PDF/JPEG и ZIP. Оригиналы не менять: проекты работают с копиями. Папки пользовательских проектов можно переносить внутри рабочей библиотеки.

Рабочая область: документы и библиотека слева, поля в центре, PDF справа. Поиск в деревьях сохраняется. Панели отделяются, скрываются независимо и возвращаются без потери ввода. Темы: матовая светлая персиковая и читаемая тёмная, мягкие скругления, единые небольшие иконки с подсказками.

Сначала использовать проверенные правила. Не предлагать случайные пустые клетки, постоянные подписи, мелкие пояснения в скобках. Неизвестные формы — сопоставление с известными и явная ручная привязка. ФИО представителей — изменяемые поля. Сохранить объединения, жирность, подчёркивание, формат даты и структуру Word/Excel.

Обучаемые образцы хранятся локально. Структура, постоянные подписи и лист Excel должны совпасть для автоматического дополнения; конфликты не разрешать угадыванием. Близкое совпадение лишь подсказывает назначение при ручном подтверждении. Каждая подтверждённая дополнительная привязка может стать новым образцом. Нумерованные пустые шаблоны копируются без изменения исходников. Личные реквизиты и ФИО пользователя загружаются из отдельного приватного файла вариантов, сохраняются при обновлениях и не входят в поставку/GitHub.

Варианты выбора — библиотека с правкой на месте. Для следующего проекта сохранять текстовые исключения, не переносить паспорта автоматически. В списках полей не копить каждое введённое слово. Колесо не меняет значение закрытого combobox. Для материалов, схем, рабочей документации и приложений выбор дописывается через запятую и пробел. Вставленный фрагмент выделяется; курсор в конце. Esc выводит из ввода.

## Переполнение

Не уменьшать текст ради размещения. Добавлять полноценную строку того же оформления, с подчёркиванием, перед пояснением в скобках. Убирать добавленные строки при уменьшении текста, без двойного подчёркивания. Одно логическое поле, например адрес, не дробить на несколько вопросов пользователю.

## Проекты, даты и связи

Из проектных PDF предлагать объект, адрес, шифр и стадию с ручной правкой. Проектные PDF в реестр ИД не включать. Обозначение раздела акта независимо от шифра проекта; несовпадение предлагается исправить, не заменяется молча.

Для каждого акта — начало/окончание работ; дата акта по умолчанию равна окончанию, отдельно изменяема. Ввод даты прост, запись точно по образцу (месяц словами, кавычки, отступы и разделители).

Нумерация актов по порядку работ. АОСР и АООК с одинаковыми отображаемыми номерами могут сосуществовать, связи не строить только по этому тексту. Изменения библиотеки применять к выбранным галочками актам, не ко всем документам без команды.

## Документы качества

Рекурсивно искать в проекте/папках паспортов и позволять отдельную загрузку позже. PDF с несколькими сертификатами делить на отдельные документы, многолистный документ сохранять целиком. Границы, тип, номер, дата и краткий материал подтверждаются и редактируются рядом с исходной страницей.

Имена отдельных PDF: порядковый номер, тип, номер и дата; материал не приписывать к имени файла. Неполную дату не выдумывать. Информационные/отказные письма могут не иметь номера и даты; отсутствующие реквизиты не дописываются. Материал сокращать по смыслу, марки металлоконструкций не добавлять автоматически, марку бетона можно указывать. В ссылках актов после полной даты — «г.».

При более чем пяти документах на акт или переполнении поля — приложение. Приложения имеют собственную сквозную нумерацию внутри раздела и не занимают номер акта. Хранятся рядом с актом и входят в реестр. Состав колонок Word-приложений сохраняется; если в форме нет количества листов и итогов, не добавлять их автоматически.

## Реестры и печать

После удаления строки все записи снизу поднимаются; после вставки и удаления пересчитать номера/страницы/суммы. Команды интерфейса запрашивают количество строк и действуют после текущей позиции, включая первую. Удаление останавливается перед ближайшей шапкой раздела/группы, не удаляет её; превышение количества сообщается после успешной операции с фактическим числом удалённых строк. Отдельный список выбора нескольких позиций не нужен. Старые одиночные вызовы сохраняют совместимость со вставкой перед первой позицией. Заголовки разделов и групп не считать документами; порядок внутри раздела начинается с 1, группы его не сбрасывают.

Пользователь вводит количество листов; страницы рассчитываются. В главном реестре нет искусственной строки «Всего позиций/листов». В реестрах качества есть расчётный итог листов. Excel печатается шириной в одну страницу, высота по содержимому. Между таблицей и «Передал» сохраняется пустая строка.

Титул один на комплект, содержит шифры использованных проектов. В порядке печати: титул → реестр → акты с приложениями, включая переходы между разделами → паспорта. Реестр строится в том же порядке. Титул и реестр не входят в номера страниц документов реестра. Поверх PDF номера не рисовать; отдельные имена для печати содержат диапазоны вида «1-2.», «3-5.», «6.».

Общий комплект по умолчанию исключает повторяющиеся паспорта, разделы могут сохранять повторы. Выбор дубликатов доступен при сборке. Дерево с галочками, связями и отметкой изменённых файлов; варианты общего/раздельного PDF, новая версия либо замена. Расчёт страниц по кнопке, с прогрессом/оценкой времени.

## Предпросмотр, сохранение и отклик

PDF только для просмотра: прокрутка непрерывная, Ctrl+колесо — масштаб у курсора, поворот на 90°, выделение/копирование текста, OCR сканов. Нажатие колёсика — ускоряемая прокрутка, повторное/Esc — отмена.

Схему можно смотреть, не закрывая редактируемый акт; поля временно выключаются, текущий акт отмечен в дереве. Временные правки показываются красным, активная строка жёлтым. При структурных операциях цвет меняется только в итогах. Цвета не попадают в сохраняемые документы и печать.

Перед закрытием — сохранить / не сохранять / вернуться. «Не сохранять» возвращает состояние проекта до сеанса; фоновые очереди должны завершиться согласованно. Черновики и резервные копии переживают перезапуск. Глобальный topmost не использовать. Дополнительные окна доступны поверх fullscreen.

Уведомления, подтверждения и ввод значений используют общие русские диалоги: компактные кнопки с иконками внизу справа, единая тема, без подсказок, повторяющих текст кнопки. Системными остаются окна выбора файлов/папок. Перенос данных акта в титул — иконка верхней ленты заполнения с подсказкой. Действия главной страницы используют те же компактные кнопки с иконками.

Тяжёлые Office/OCR/PDF-операции не выполнять в Tk-потоке. Рисовать только видимые PDF-страницы, ограничивать кэш, отменять устаревшие запросы, не запускать постоянный сканер диска.
