# Текущее состояние

Последнее обновление: 03.11.2026.

Рабочее приложение запускается через `Бюро ИД.cmd` → `app/workspace_preview.py` → `studio.Studio`. GitHub — история исходников; локальные проекты, библиотека и исследовательские материалы в Git не входят.

## Реализовано и проверено

- Направляющие PDF: общая геометрия угла/горизонтальной и вертикальной полос, непрерывный фон в полях и между страницами; ширина номеров по тексту, номера на всех видимых страницах. Повторные шапки Excel поддерживаются, лишние границы вне печатной области отфильтрованы. Направляющие включены только для моделей реестров/приложений с позициями.
- Кнопки библиотеки прижаты вправо в одном ряду. Fullscreen-панель задач раскрывается и при активном модальном окне приложения; модальный захват сохраняется.

- PDF: физические линейки Word/PDF, шапки строк/столбцов Excel по геометрии печати Office, подсветка текущей привязки и выбор позиции реестра по номеру строки. Для сложных областей печати — физическая линейка без выдуманных номеров.
- Обновление PDF того же документа удерживает предыдущий кадр, сохраняет положение; строка предварительного просмотра больше не меняет высоту холста. В библиотеке две нижние команды в одном ряду, иконки переименования/удаления шаблона с подсказками.

- Пакетные позиции реестров: количество для добавления/удаления после текущей позиции, без лишнего списка Ctrl/Shift; удаление ограничено ближайшей шапкой. При превышении — сообщение с фактическим количеством после успешной операции. В общем Excel-реестре — копирование раздела с очисткой значений позиций и удаление раздела (последний сохраняется). Иконки с подсказками вынесены во второй ряд панели заполнения; проверены границы закреплённой и узкой отдельной панели.

- Существующие Excel/Word формы, явные привязки, сохранение форматирования и дат.
- Просмотр PDF в отдельном процессе, непрерывные страницы, повороты, копирование, OCR сканов и средняя кнопка мыши.
- Сохраняющие ввод панели, отдельные вспомогательные окна, fullscreen, ленты, темы и подсказки.
- Стеклянный drag с маршрутизацией release над стеклом, линией и исходными полями, снятием grab при отмене.
- Очередь структурных операций реестра без ожидания PDF, вставка перед первой позицией и пересчёт номеров/страниц/сумм.
- Чистые документы и печатный PDF отдельно от цветного review PDF, черновики и обратимое сохранение.

## Изменения интерфейса 03.11.2026

- Общие русские диалоги уведомления/подтверждения/ввода вместо native messagebox/simpledialog. Компактные иконки-кнопки, две темы, владелец fullscreen, отмена и возврат захвата родительскому окну. Длинные уведомления прокручиваются.
- Кнопки главной и библиотеки приведены к Compact; заполнение титула из акта перенесено в верхнюю ленту. Каталог качества использует компактное действие справа внизу.
- Новые проверки: verify_app_dialogs; verify_counted_rows (сгенерированные Excel/Word, вставка после первой, границы удаления, порядок, формулы и страницы).

- Один неподвижный непрозрачный canvas под стеклянными карточками при drag: старый разделитель не просвечивает и нативные окна не перемещаются каждый кадр.
- Окна паспортов/сборки: те же компактные оконные символы, без отделения; сворачивание в панель задач Windows.
- Подсказки только для иконок и опций, без дублирования полноразмерных кнопок.
- Нижние 24px полноэкранного окна раскрывают системную панель плавной маской, без перестроения содержимого и изменения настроек ОС.
- Исходники `app/`, проверки `tests/`, запуск «Бюро ИД.cmd».

## Сохранение и скорость — уточнение 03.11.2026

- Office редактирует отдельные файлы в `.recovery/working/`; исходный файл меняется только по явному «Сохранить». Переименование меняет путь действующего сеанса без его перезапуска.
- Начальное состояние проекта неизменно до закрытия проекта. Сохранение отдельного документа создаёт отдельную контрольную копию, но не отменяет возможность откатить весь проект к открытию.
- Два тёплых сеанса Office, остальные освобождаются; повторный переход не требует повторного запуска. Чистый PDF отправляется в интерфейс до цветного экспорта. Повторный ввод того же значения не запускает обработку; запись восстановления отложена до паузы ввода.
- Скрытие панели задач учитывает её продвижение Windows при миниатюрах/Aero Peek; временный порядок окон восстанавливается при уходе из приложения.
- Подсветка пунктов меню: тёмный текст на светлом фоне, как у иконок.

## Что ещё требуется

- Полная проверка на разнообразных незнакомых формах и большом количестве реальных комплектов. Универсальное распознавание не обещается; спорные места требуют подтверждения.
- Проверка распознавания реквизитов/границ сканов пользователем. Номера/даты нельзя угадывать.
- Оптимизация Office-экспорта на конкретных больших файлах: он не становится мгновенным от замены просмотрщика.
- Полная генерация исполнительных схем не реализована; пока просмотр и текстовая ссылка.
- Отдельная установка/EXE и проверка распространения зависимостей.
- Обычный Git HTTPS требует локальной авторизации. Доступ GitHub-коннектора действует независимо; порядок обхода без секретов описан в SYNC.

## PDF tiles v1

Масштабирование: Ctrl+колесо объединяется в кадры 16 мс; во время движения используется обзор видимой области, точные плитки запрашиваются после паузы 140 мс. Устаревшие задания/результаты удаляются; до четырёх результатов за проход с бюджетом 6 мс между установками. Готовый обзор заменяет дорогой readback плиток при обычном масштабе. Повторный show того же PDF не отменяет движение. На копии реальной схемы в одном сравнительном прогоне: первый отклик 426 → 60 мс, чёткая видимая область 511 → 534 мс от начала жеста. Это улучшение интерактивности, не ускорение native-расчёта PDF. PASS: verify_pdf_zoom, verify_pdf_tiles, verify_async_pdf, verify_pdf_selection, verify_fast_preview.

Доработка: запас точных плиток вокруг окна, сохранение полезных результатов при перемещении, переходный кадр при масштабе, повторное использование обзорной подложки. PDF-процесс читает снимок байтов, не удерживая исходный файл открытым. Удаление открытой схемы и точный откат проекта проверены на временном проекте. Шаблоны разложены по категориям без проектной подпапки; коллизии имён сохраняются.

Большие листы: видимые плитки, обзорная подложка, кэш native-страниц/текста, удаление устаревшей очереди. Точные плитки ограничены 48 МиБ. Эталонная проверка пикселей при четырёх поворотах, прокрутка и закрытие: PASS. Синтетические проверки не заменяют замер пользовательской тяжёлой схемы. Детали: docs/PDF_VIEWER_PLAN.md.
