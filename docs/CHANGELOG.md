# Изменения

## 03.11.2026 — направляющие PDF и компактная библиотека

- Верхняя/левая физические линейки; в Excel с поддержанной областью печати — буквы столбцов и номера строк, полученные из Office. Текущая ячейка подсвечивается; щелчок по номеру позиции реестра выбирает её поля. Многообластная печать, повторные шапки, несколько видимых листов и сложное масштабирование используют физическую линейку.
- Новый PDF той же сессии не очищает отображённый кадр до готовности замены; сохранён относительный scroll, стабилизирована высота уведомления предварительного вида. При смене документа старый кадр не сохраняется.
- Нижние команды библиотеки стоят рядом и учитываются минимальной шириной; добавлены иконки переименования/удаления шаблонов с подсказками и подтверждением удаления.
- Проверки: verify_pdf_guides_library (сгенерированный Office: координаты номера строки совпали с PDF-текстом, кадр удерживается, кнопки и операции библиотеки), verify_batch_register, verify_panel_fit, verify_pdf_tiles, verify_fast_preview, verify_async_pdf, verify_rename_transaction, verify_word_transaction. Исходные пользовательские документы не изменялись тестами.

## 03.11.2026 — PDF, шаблоны и удаление схем

- Точные плитки подгружаются с запасом вокруг окна; полезный результат предыдущей области не выбрасывается. Перемещение сохраняет исходные чёткие bitmap; при масштабе предыдущий кадр показывается до уточнения. Повторные запросы уже выполняемой плитки исключаются, неизменная обзорная подложка не пересоздаётся.
- PDF-процесс открывает снимок байтов, освобождая исходный файл для удаления/переименования. При удалении текущей схемы снимается режим её просмотра; удаление записывается в восстановительный журнал.
- Существующие шаблоны перенесены в Титулы/АОСР/АООК/Приложения/Реестры/Приказы; будущие импорт и сохранение используют категории. Разные файлы с одинаковым именем не перезаписываются.
- Проверки: базовая проверка, PDF tiles/async/selection/fast preview, сгенерированный проект delete/templates, неизменный baseline и транзакции Excel/Word. Пользовательские оригиналы не использовались для изменения в тестах. Процент ускорения реальных схем не установлен.

## 03.11.2026 — единые диалоги и операции по количеству

- Все вызовы уведомления, подтверждения и ввода переведены на app_dialogs; русский текст кнопок, общая Compact-поверхность с иконками, действия внизу справа, длинный текст прокручивается. Выбор файлов остаётся системным.
- Добавление/удаление интерфейса — по количеству после текущей позиции. Удаление ограничено следующей шапкой; после успеха сообщает фактически удалённое число, если запрос превышен. Убран лишний список четырёх позиций. Excel/Word сохраняют отдельную реализацию и старые одиночные вызовы.
- Перенос данных акта в титул — иконка панели заполнения. Главная, библиотека и выбор качества используют компактные кнопки с иконками.
- PASS: check_project, verify_app_dialogs (обе темы/fullscreen/ввод/отмена/главная), verify_counted_rows (временные Excel и Word; соседние записи, формулы, страницы, нумерация).

## 03.11.2026 — пакетные операции реестров

- Общие команды одной/нескольких позиций: Ctrl/Shift для удаления, количество для вставки; прежние правила первой позиции, очистки последней строки, нумерации и чистого PDF сохранены. Пакет записывается и экспортируется один раз.
- Общий реестр Excel: новый раздел по образцу текущего (оформление и группы сохраняются, значения позиций очищаются), удаление раздела с подтверждением названия и числа позиций; последний раздел защищён. Непривязанные разделы Word не угадываются.
- Обновлены парные иконки строк и разделов; отдельный ряд с общими подсказками учитывается расчётом минимальной ширины.
- Проверены с Office: verify_batch_register (сгенерированный Excel, пакетные операции и размещение иконок), verify_structural_review, verify_word_first_row, verify_panel_fit, verify_rename_transaction и verify_word_transaction; базовая check_project.
