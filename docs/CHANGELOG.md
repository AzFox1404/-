# Изменения

## 02.11.2026 — объединение в GitHub-проект

- Собраны код, PowerShell workers, vendor, регрессионные проверки, карта модулей и подтверждённые требования.
- Рабочие документы, кэши, выгрузки, снимки и приватная история исключены из Git.
- Добавлены общие пути с локальными переопределениями, переносимый запуск и зависимости.
- Для известных Excel-актов сохранены обезличенные статические якоря. Резервное распознавание без локальных заполненных шаблонов сверено с прежними картами на 19 формах.
- Закреплён порядок GitHub → рабочая папка с проверкой локальных правок и SHA, без фонового сканирования диска.

## Предшествующее состояние приложения

- Исправлены pane drag/release и блокировка захвата мыши.
- Вспомогательные окна получили ленты и только X в native-заголовке; панели скрываются отдельно, сохраняя ввод и PDF-процесс.
- Исправлены очередь операций, сдвиги записей и вставка на первой позиции Excel/Word реестров; подписи не окрашиваются от смещения строк.
- Отрисовка PDF изолирована, данные OCR и кэш ограничены; экспорт без временных цветов.

Подробная хронология конкретных клиентских примеров остаётся локальной.
